Ankh Do is a simple to-do list and task manager that lives in your browser toolbar. Click the icon, type a task, press Enter. That's it.

Keep track of what you need to do without opening a new tab or signing up for anything. Check tasks off as you finish them, and use the built-in task timer to see how long each one takes. The timer keeps running even when the popup is closed, so it works for time tracking too.

Features:
• Quick to-do list: add a task and press Enter, then add the next one
• Checklist: mark tasks done with one click
• Task timer: start and pause a stopwatch on any task
• Drag and drop to reorder tasks and set priorities
• Edit a task in place, copy its text, or delete it, with Undo if you change your mind
• Badge on the toolbar icon shows how many tasks are still open
• Clear all completed tasks in one step
• Dark theme and a light off-white theme, chosen in Options
• Full keyboard shortcuts

Keyboard shortcuts:
Up/Down: move between tasks
Alt+Up/Down: move a task up or down
Space: mark as done
Enter or F2: edit
T: start or pause the timer
C: copy
Delete: delete
Esc: cancel or close

A calm, pharaonic design: gold and papyrus on black basalt, with an ankh in your toolbar.

Private by design: your tasks are saved locally in your browser and never leave your computer. No account, no sign-up, no internet connection, and no data collection.

Great for daily planning, work tasks, study, shopping lists, and anything you want to get done.
